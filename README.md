# RoadRacer

Учебный 2D-гоночный проект на JavaFX: редактор трасс со свободным рисованием мышью и простой гоночный режим.

## Требования
- JDK 21
- Gradle (или Gradle Wrapper, который можно добавить через `gradle wrapper`)
- Интернет при первой сборке для загрузки зависимостей

## Запуск
В каталоге проекта:

```bash
gradle run
```

Если в системе установлен только JDK, установите Gradle или откройте проект в IntelliJ IDEA как Gradle-проект.

## Управление
- W / стрелка вверх — газ
- S / стрелка вниз — тормоз / задний ход
- A, D / стрелки влево, вправо — поворот

## Редактор
Зажмите левую кнопку мыши и проведите линию — это центральная линия дороги. Настройте ширину, нажмите «Старт здесь», сохраните трассу в JSON. Кнопка «Начать гонку» запускает автомобиль на созданной трассе.

## Структура
- `app/RoadRacerApp.java` — запуск и переключение экранов
- `model/Track.java`, `model/Vec2.java` — данные трассы и геометрия
- `editor/TrackEditorView.java` — редактор мышью
- `game/Car.java` — движение и простая проверка выезда с дороги
- `game/RaceView.java` — игровой цикл и ввод
- `render/TrackRenderer.java`, `render/CarRenderer.java` — отрисовка
- `io/TrackStore.java` — JSON сохранение и загрузка

## Ограничения первой версии
Это рабочий каркас, а не законченный гоночный симулятор: круги и финишная логика, камера слежения, сглаживание линии и более точная коллизия пока не реализованы. Трасса сейчас проверяется как набор отрезков центральной линии.
